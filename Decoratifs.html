DECORATIFS

UI DESIGNER / PROGRAMMER

PROJECT SUMMARY


Decoratifs is a UI design project themed around Art Deco buildings. This was a University project where I was given a framework to develop a functional UI system for. I decided to go for a style I really love that I rarely see!

For this project, I used Photoshop and Krita to create a wealth of custom unique assets. I then used Unreal Engines Widget system to implement functionality with the frameworks systems. I spent a lot of time focusing on desiging and polishing the UI to make it feel well themed and animated (without drawing attention away from the game).

CONTRIBUTIONS

Photoshop / Krita to develop unique UI assets
Unreal Engine 5 Widget system for UI implementation
UI Design using Figma and Miro
Grapic design research and theory to support the design
