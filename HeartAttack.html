HEART ATTACK

DESIGN / PROGRAMMING

PROJECT SUMMARY


Heart attack is a small wave fighter game developed using Unity. This was my first introduction to the software and I thoroughly enjoyed learning it.

I focused this project on getting a basic understanding of the software and developing a fun mechanic that also challenged me to engage with the engine as much as possible. Although I struggled with coding to begin with, I felt that time went on I slowly got a better understanding of how to use the tools.
