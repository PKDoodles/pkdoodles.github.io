TALKING TANKS

DESIGNER / PROGRAMMER GDD

PROJECT SUMMARY


Talking Tanks is a 2 player co-op game where one person controls a Tank in VR and another helps navigate them around a perilous envrionemnt using a bespoke controller. This project was developed between me and friend to try and branch ourselves outside the typical game development process. It was incredibly fun!

For this project, I was responsible for a wealth of elements. The main one focused was development of a bespoke controller using wiring and an arduino to create a unique controller. Furthermore I also designed the level and programmed a lot of the core mechanics, most notably the grid and co-ordinate system.
