PROJECT SUMMARY


BellSong is a small stealth game project I worked on to experiment with the more advance development tools of unreal engine blueprints. I aimed to create a short yet fullfilling micrograme using a framework. This was also my first lookinbg into AI so I wanted a small project that pushed me!

For this project, I grasped the fundamentals of UI design and implementation as well as player controller's and game modes. I also experimented with isometric movement and gameplay, which was very fun!
